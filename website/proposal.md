# têtu 홈페이지 개선 제안

2026.09 · Website Renewal Proposal

## 제안 개요
본질은 그대로, 경험은 더 깊게. 브랜드의 절제된 감도를 유지하면서 ‘브랜드 인지 → 컬렉션 발견 → 상품 탐색 → 구매 판단’의 흐름을 연결합니다.

## 진단 범위
공개 홈페이지, 브랜드 스토리, 컬렉션 페이지와 데스크톱 첫 화면을 참고한 정성 제안입니다. 운영 분석 데이터, 결제 과정, 모바일 실기기 검증, 정량 성능 측정은 수행하지 않았습니다. 기대 효과는 검증할 가설이며 보장된 성과가 아닙니다.

## 현재 관찰
- 홈페이지 첫 화면은 큰 캠페인 이미지 중심으로 구성됩니다.
- ABOUT과 COLLECTION이 상단에 있고 SHOP과 세부 카테고리는 펼침 메뉴에서 확인됩니다.
- 브랜드 스토리와 시즌별 컬렉션이 별도 페이지로 운영됩니다.

## 제안하는 메인 페이지 구성
1. 헤더: SHOP · COLLECTION · ABOUT / 검색 · 계정 · 장바구니
2. 캠페인: 대표 이미지 + 브랜드 메시지 + 컬렉션 진입 버튼
3. 주요 상품: 시즌의 핵심 상품 및 카테고리 탐색
4. 컬렉션: 룩북과 착용 상품 연결
5. 브랜드 스토리: 철학, 소재, 제작의 이야기
6. 푸터: 고객 지원 및 배송·교환·반품 안내

## 핵심 개선안
### 01. 브랜드를 담은 첫 화면 — 우선 적용
이미지, 한 문장의 브랜드 메시지, 명확한 탐색 버튼을 배치합니다. 메인에서 컬렉션·상품으로 이동하는 비율과 핵심 콘텐츠 도달률을 검증합니다.

### 02. 헤매지 않는 상품 탐색 — 우선 적용
상단 SHOP 노출, 명확한 카테고리, 사이즈·컬러 필터, 정렬을 설계합니다. 뒤로 이동 시 탐색 상태를 유지합니다. 쇼핑 진입률과 검색·필터 이후 상세 진입률을 확인합니다.

### 03. 모바일에서도 온전한 경험 — 우선 적용
기기별 이미지 크롭과 읽기 편한 텍스트, 최소 44px 터치 영역, 명확한 메뉴 닫기와 하단 구매 행동을 설계합니다. iOS·Android 실제 기기에서 주요 흐름을 검증합니다.

### 04. 컬렉션에서 일상으로 — 경험 확장
룩북 아래 착용 상품을 연결하고, 시즌 아카이브와 품절 시 대안을 정리합니다. 컬렉션에서 상품 상세 이동률을 확인합니다.

### 05. 선택에 필요한 확신 — 경험 확장
소재, 핏, 실측, 모델 착용, 배송, 교환·반품 정보를 일관된 형식으로 제시합니다. 옵션 선택 완료율과 문의 유형을 점검합니다.

### 06. 기다림 없이, 누구에게나 — 지속 개선
반응형 이미지, WebP/AVIF 및 지연 로딩을 적용합니다. 키보드 조작, 포커스, 대체 텍스트, 색상 대비를 검증하고 Core Web Vitals를 측정합니다.

## 실행 순서
1. 진단과 설계: 이용 흐름 및 데이터 검토, 콘텐츠 정리, 사이트맵, 와이어프레임
2. 디자인과 구현: 비주얼 시스템, 반응형 메인, 탐색·상품 상세 구현
3. 검증과 지속 개선: 모바일·접근성·성능 QA, 여정 측정, 개선 백로그

일정·비용은 콘텐츠 준비 상태, 쇼핑몰 솔루션 제약, 연동 범위를 확인한 후 산정합니다.
